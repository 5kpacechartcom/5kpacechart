# 5kpacechart.com — Running Pace Charts & Calculators

**Live → [5kpacechart.com](https://5kpacechart.com)**

Free running pace charts and calculators for every race distance — 5K, 10K, half marathon, marathon, and mile.

## Tools

- [5K Pace Chart](https://5kpacechart.com/) — pace chart for finish times 15–60 min, per-mile and per-km
- [10K Pace Chart](https://5kpacechart.com/10k-pace-chart/) — finish times 30–90 min
- [Marathon Pace Chart](https://5kpacechart.com/marathon-pace-chart/) — 2:30–6:00 with Boston Qualifier times and race splits
- [Half Marathon Pace Chart](https://5kpacechart.com/half-marathon-pace-chart/) — 1:30–3:00
- [5K Pace Calculator](https://5kpacechart.com/5k-pace-calculator/) — convert finish time to pace or pace to finish time
- [Mile Pace Calculator](https://5kpacechart.com/mile-pace-calculator/) — convert between min/mile and min/km
- [Running Pace Calculator](https://5kpacechart.com/running-pace-calculator/) — find pace, time, or distance for any race
- [Half Marathon Pace Calculator](https://5kpacechart.com/half-marathon-pace-calculator/)
- [Garmin Heart Rate Zones](https://5kpacechart.com/garmin-heart-rate-zones/)
- [All Tools](https://5kpacechart.com/tools/)

All calculations use precise race distances (5K = 5.000 km = 3.10686 mi, 10K = 10.000 km = 6.21371 mi, half marathon = 21.0975 km = 13.1094 mi).

## Self-hosting

```bash
git clone https://github.com/5kpacechartcom/5kpacechart.git
cd 5kpacechart
# open index.html directly or serve with:
npx serve .
```
